# nimrahnaeem.github.io

Personal portfolio of Nimrah Naeem, AI & Machine Learning Engineer. Live at https://nimrahnaeem.github.io.

Built with React, TypeScript and Vite. No UI framework; styles are in `src/styles.css`.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All text, metrics, projects and skills live in [`src/data.ts`](src/data.ts). Keep it in line with the CV.

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages through `.github/workflows/deploy.yml`.
